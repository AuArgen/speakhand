# Сүйлө — кыргыз жест тили котормочу

**Бири сүйлөйт, экинчиси жаңсайт — экөө бири-бирин түшүнөт.** Эки түзмөктөгү эки адам бир бөлмөдө сүйлөшөт:

- **Сүйлөөчү** (угат, сүйлөйт) → сөзү жаңсоочунун экранында чоң текст жана **3D аватардын жести** болуп чыгат.
- **Жаңсоочу** (жест тилинде сүйлөйт) → камерага көрсөткөн жести, же бир басуу менен тандаган даяр сүйлөм/сөз → сүйлөөчүнүн экранында текст жана **үн** болуп чыгат.

Каттоо жок: «Бөлмө ачуу» → 6 сандуу код жана QR → экинчи адам код менен кирет. Тарых сакталат — ошол эле код менен кийин уланта берсе болот.

Даяр сүйлөмдөр, сөздөр жана жесттерди таануу **AI'сыз, интернетсиз, дароо** иштейт. AI (компьютердеги `claude` CLI) — жаңы татаал сүйлөмдөр үчүн гана, каалоо боюнча.

## Ишке киргизүү

```powershell
npm install
npm run dev          # бир компьютерде: http://localhost:8787
```

### Эки телефон менен (ошол эле Wi-Fi)

Телефондор камера жана микрофонду HTTPS аркылуу гана берет:

```powershell
npm run start:lan    # курат жана HTTPS'те иштетет; телефон үчүн даректи басып чыгарат
```

1. Терминалда чыккан даректи (мис. `https://192.168.1.146:8787`) биринчи телефондо ачыңыз — сертификат өзү кол коюлган, браузер эскертсе «Баары бир өтүү» басыңыз.
2. «Бөлмө ачуу» → ролду тандаңыз. QR же 6 сандуу код чыгат.
3. Экинчи телефон QR'ди сканерлейт же «Код менен кирүү».

`npm run dev:lan` — ошол эле, бирок иштеп чыгуу режиминде (код өзгөргөндө өзү жаңырат).

### Docker (VPS / сервер) + nginx

Серверде Docker, Docker Compose жана nginx болушу керек. **Тиркеме сыртка эч бир порт ачпайт** — ал серверде `127.0.0.1:8787`'де гана угат, сырттан кирүү nginx аркылуу гана.

```bash
git clone https://github.com/AuArgen/speakhand.git && cd speakhand
cp .env.example .env

docker compose up -d --build                           # тиркеме → 127.0.0.1:8787 (сыртка жабык)
docker compose --profile tts up -d --build             # + кыргызча үн (MMS-TTS, Docker ички тармагында гана)
```

**nginx — https://sh.primeactive.net** (домен Cloudflare проксиси аркылуу өтөт):

1. Cloudflare → SSL/TLS → Overview: режим **Full (strict)**.
2. Cloudflare → SSL/TLS → Origin Server → **Create Certificate** (`sh.primeactive.net`) → серверде сактаңыз:
   ```bash
   sudo mkdir -p /etc/ssl/cloudflare
   sudo nano /etc/ssl/cloudflare/sh.primeactive.net.pem    # Origin Certificate
   sudo nano /etc/ssl/cloudflare/sh.primeactive.net.key    # Private Key
   sudo chmod 600 /etc/ssl/cloudflare/sh.primeactive.net.key
   ```
3. nginx:
   ```bash
   sudo cp deploy/nginx/speakhand.conf /etc/nginx/sites-available/speakhand.conf
   sudo ln -s /etc/nginx/sites-available/speakhand.conf /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   ```

Конфигде: http → https, WebSocket (`/ws`), колдонуучунун чыныгы IP'си Cloudflare'дин `CF-Connecting-IP`'синен (Cloudflare'дин расмий IP диапазондорунан келгенде гана — жасалма башкы четке кагылат). nginx 1.18 (Ubuntu 22.04) жана азыркы stable версияларында текшерилген. Сервердин A-жазуусу Cloudflare DNS'те кызгылт сары булут (Proxied) абалында болушу керек.

- Бөлмөлөр жана котормо кэши `suylo-data` томунда сакталат — контейнер жаңырса да жоголбойт.
- Серверде Claude CLI жок — тиркеме AI'сыз режимде иштейт (даяр котормолор + сөздүк эрежелери); бул кадимки абал.
- Абалы: `docker compose ps` (healthy болушу керек), логдор: `docker compose logs -f app`, жаңыртуу: `git pull && docker compose up -d --build`.
- Портту текшерүү: `ss -ltnp | grep 8787` → `127.0.0.1:8787` гана болушу керек (`0.0.0.0` эмес).

### Кошумча

- Кыргызча үн (MMS-TTS): `npm run tts:setup` (бир жолу), анан `npm run tts` же баарын бирге `npm run dev:all`. Иштебесе браузердин үнү колдонулат.
- Даяр сүйлөмдөрдү кошуу: `scripts/phrases.txt` → `npm run phrasebook` (AI бир гана жолу которот, натыйжа `server/data/phrasebook.json`).
- Тесттер: `npm run test:rooms` (бөлмөлөр), `npx tsx src/vision/selftest.ts` (таануу).

## Кантип иштейт

| Багыт | Жол | AI |
|---|---|---|
| Сөз → жест | Web Speech (ky-KG) → даяр котормо / сакталган котормо / сөздүк эрежелери (184 фраза-жест, ысымдар тамгаланат) → 3D аватар | Жок (жаңы татаал сүйлөм үчүн каалоо боюнча) |
| Жест → сөз | MediaPipe (кол, дене, бет) → DTW k-NN, 1283 жесттин алдын ала эсептелген үлгүлөрү (~40 мс) → даяр сүйлөмдөн же сөздөрдөн сүйлөм → үн | Жок |
| Даяр сүйлөм/сөз | Бир басуу → дароо жөнөтүлөт | Жок |

**Жест китепканасы:** 1371 клип / 1283 кыргызча глосс — «Русский жестовый язык» видеосабактарынан (YouTube, Енох Иаредович / Голос Истины) MediaPipe менен тартылып алынган кыймыл маалыматы (видеонун өзү эмес). Кыргыз жест тили орус жест тилине жакын. **Ачык/конкурста колдонуудан мурун автордон уруксат алыңыз.** Кайра түзүү: `tools/rsl_import/README.md`.

**3D аватар:** Blender + MPFB (MakeHuman, CC0 ресурстар), манжалуу риг жана ARKit бет формалары — `public/models/avatar.glb`, түп нускасы `assets/avatar.blend`.

```
  components/room/                   бөлмөнүн бөлүктөрү (timeline, микрофон, аватар сахнасы, камера, даяр сүйлөмдөр, сөздөр, QR)
  pages/{Translate,Recognize,Studio,Dictionary}Page.tsx   «Куралдар»: котормо, таануу, жест жаздыруу студиясы, сөздүк
  lib/room.ts        бөлмө протоколу + WebSocket кардары (кайра туташуу, кезек)
  lib/compose.ts     глосстор → кыргызча сүйлөм (AI'сыз)
  lib/recognizer.ts  таануу модели (жаңсоочунун түзмөгүндө гана жүктөлөт)
  avatar/            three.js аватар, IK, mocap retargeting, дактилология
  vision/            MediaPipe tracker, белгилер, DTW классификатор, сегментатор
  data/              сөздүк (IndexedDB), жест китепканасы (керек болгондо жүктөлөт)
server/
  app.ts, rooms.ts   HTTP/WebSocket сервер, бөлмөлөр (server/data/rooms), LAN HTTPS
  gloss.ts, phrasebook.ts, vocabulary.ts   котормо: даяр → сакталган → эрежелер → (AI)
public/signs/rsl/    жест китепканасы: manifest, клиптер (.json.gz), таануу үлгүлөрү
tools/rsl_import/    видеосабактардан жест китепканасын түзүү (Python, MediaPipe)
tts/                 кыргызча MMS-TTS кызматы (Python, кошумча)
```

## Чектөөлөр

- Китепканадагы жесттер орус жест тилинен (РЖЯ); кыргыз жест тилинде айырмаланган сөздөрдү жест тилин билген адам **Студияда** жаздырышы керек — жаздырылган жест китепканадагыдан артыкчылыктуу.
- Үзгүлтүксүз тез жест тилин толук таануу — дүйнөдө деле изилдөө маселеси; система ар бир жесттен кийин кыска тыныш күтөт. Таануунун босоголору синтетикалык сыноодо жөндөлгөн — чыныгы камера менен текшерип тууралоо керек.
- Кыргызча үн таануу Chrome'дун кызматына көз каранды (интернет керек); иштебесе орусча режим же жазуу.
- LAN режиминин (`npm run start:lan`) сертификаты өзү кол коюлган — ар бир телефон бир жолу эскертүүнү өтүшү керек. Интернет аркылуу колдонуу үчүн — жогорудагы Docker + nginx.
