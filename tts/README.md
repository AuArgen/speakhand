# Кыргызча TTS (милдеттүү эмес)

Бул жергиликтүү микросервис Meta'нын `facebook/mms-tts-kir` (VITS) моделин колдонуп, кыргызча текстти үнгө айландырат. Иштебесе, колдонмо браузердин үнүнө өтөт.

## Орнотуу
```powershell
cd tts
./setup.ps1     # .venv түзөт, пакеттерди жана моделди жүктөйт (~1 ГБ+)
./run.ps1       # http://127.0.0.1:8790
```

## API
- `GET /health` -> `{"ok": true, "model": "facebook/mms-tts-kir"}`
- `POST /tts` `{"text": "Саламатсызбы"}` -> `audio/wav`

Узун текст сүйлөмдөргө бөлүнөт, акыркы жыйынтыктар кэште сакталат. Сервер 127.0.0.1'де гана угат.
